🔌 API INTEGRATION

   Base URL: https://store-app-exqx.onrender.com

   Endpoints Used:
   
   GET  /api/products
        ↓ Fetch live catalogue with pagination
   
   GET  /api/auth/me
        ↓ Check if user is signed in (from session cookie)
   
   GET  /api/auth/google
        ↓ Redirect to Google OAuth (opened in browser)
   
   POST /api/orders/checkout
        ↓ Create order + get Paystack authorization URL

   Backend Responsibilities (NEVER on mobile):
   • Google OAuth secret management
   • Session/cookie management
   • Stock validation
   • Order creation & persistence
   • Paystack secret keys
   • Payment processing
   • Mailgun email delivery
